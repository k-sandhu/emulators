# emulators

High-fidelity local emulators of the SaaS APIs our products integrate with — Microsoft
Graph (Entra ID, Outlook, OneDrive/SharePoint, Teams, online meetings), Google Workspace
(Directory, Drive, Gmail, Calendar, Meet), Box, Dropbox, Stripe, Twilio, WhatsApp,
Messenger, Salesforce, QuickBooks Online, Zoom and Slack — so integration tests can run
against realistic data, users, hierarchies and permissions without vendor accounts.

> Work in progress. See [AGENTS.md](AGENTS.md) for the architecture and contribution rules.
